Guide d'Utilisation

Planificateur IA : Accédez au module "Gestion des Trajets" pour planifier vos déplacements.

Étapes :
  1. Saisissez votre point de départ et votre destination
  2. Choisissez vos critères d'optimisation : rapidité, économie ou écologie
  3. Sélectionnez vos types de véhicules préférés (bus, vélo, voiture, marche)
  4. L'IA vous propose plusieurs options optimisées avec temps, coût et impact écologique

Tableau de bord personnel : Accédez à /trajets/ pour voir :

  • Statistiques : Vos trajets totaux, trajets du jour, véhicules disponibles
  • Actions rapides : Planifier, consulter l'historique, voir les infos temps réel
  • Derniers trajets : Historique avec possibilité de répéter un trajet
  • Alertes transport : Perturbations en cours
  • Préférences : Vos critères d'optimisation par défaut

Données Live : Consultez les informations en temps réel pour optimiser vos déplacements.

Disponible :
  • Horaires bus/métro : Passages en temps réel
  • Alertes trafic : Embouteillages, accidents, travaux
  • Véhicules partagés : Disponibilité vélos, trottinettes
  • Perturbations : Retards, annulations, déviations

Personnalisation : Configurez vos préférences pour des recommandations plus précises.

Paramètres disponibles :
  • Priorité par défaut : Rapidité, économie ou écologie
  • Budget maximum : Limite de coût acceptée
  • Durée maximale : Temps de trajet limite
  • Types de véhicules : Vos préférences de transport
  • Lieux favoris : Domicile, travail, autres lieux fréquents

Navigation facile : Trouvez rapidement ce que vous cherchez.

Éléments d'interface :
  • Menu principal : "Modules SmartCity" → Accès aux fonctionnalités
  • Dashboard : Votre tableau de bord personnel
  • Bouton flottant (coin droit) : Accès rapide aux modules
  • Footer : Liens directs vers chaque gestion
